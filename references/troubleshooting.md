# 质检问题速查（看 qa/pNN_cmp.jpg 后按病对症，改完只重跑该页）

| 症状 | 病根 | 修法 |
|---|---|---|
| 某行文字位置/字号明显不对（偏移、变小、字距拉大） | 该 zone 的 bbox 没框住实际墨迹，引擎在空框里测量失败退默认值 | 对照 `ocr/pNN.json` 找到该行的 OCR 框，把 zone bbox 改到贴住墨迹，ocr_ids 填对应行号 |
| 转写文字有错字 | 抄写笔误 | 直接改 lines 里的字（OCR 候选一般是对的，以图为准） |
| 标题出现两套重影 | 同一段文字既标了 calligraphy 又建了 text_zone | 删掉重复的那个（书法/艺术字保留 calligraphy） |
| 物品图层是碎块/黑斑，或把旁边东西吸进来了 | 物件框大而虚（内容大半是背景），或框错了位置 | bbox 收紧到物件本身，notes 写英文物体名；纯背景大件（房屋、远景）直接删掉这个 object，留在背景即可 |
| 人物缺胳膊/少下半身 | bbox 没包全 | 放大 bbox 包住整个人（含被遮挡前的部分）；躺姿人物是已知限制，抠不全时可删掉 persons 条目整体留背景 |
| 贴纸/徽章/气泡被撕成两半 | 没有单独标 object，被邻近大层吸走 | 加一个 objects 条目，框紧贴贴纸（含它的小装饰），method:grabcut |
| 出现内容为空的图层 | 彩色渐变装饰条被标成了 panel | 删掉该 panel，条目写进 decor_keep_in_bg |
| 文字底下的卡片/白板没分出来 | 漏标 panel | 补 panels 条目（半透明的 fill 选 translucent_*） |
| 密排小字排版乱 | 小字转可编辑文字的固有难点 | 接受引擎默认（整块成层保真）；用户坚持要编辑时把该 zone style 改 "plain" 重跑单页看效果 |
| 还原度分数差但肉眼看对比图没问题 | 渲染器口径差异（半透明层合成偏差） | 以肉眼对比 cmp 图为准，分数仅供参考 |
| 拖走图层后背景有残影/幻字 | 引擎清扫遗漏 | 直接重跑该页一次（清扫是多轮收敛的，重跑通常即净）；仍在则把残影处坐标发给用户确认是否原图设计元素 |

## 通用原则

- 宁缺毋滥：识别不准的元素留在背景里视觉无损；抠错了才刺眼。
- 每次只改一处，重跑单页验证，别一次改一堆。
- 重跑单页免费且快（`zsh pipeline/rerun_pages.sh <deck> <页码>`，秒级到分钟级）。

## 渲染器故障

| 症状 | 修法 |
|---|---|
| PowerPoint 报 -9074 或导出卡死 | 先删掉 work/<deck>/calib/ 下 `~$` 开头的锁文件，彻底退出 PowerPoint（必要时 `pkill -9 -f "Microsoft PowerPoint"`）再重跑；反复出现就改用 LibreOffice：`SLIDELIFT_RENDERER=libreoffice zsh pipeline/run_all.sh <deck>` |
| 无任何渲染器 | 质检渲染会失败，但分层与组装产物不受影响——`output/` 的 PPTX 仍可用，只是没有对比图 |
